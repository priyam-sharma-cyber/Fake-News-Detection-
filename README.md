# Fake News Detection System

A Machine Learning project that classifies news as Real or Fake using Logistic Regression and TF-IDF.

## Live Demo
https://mzihhbenkvptqobambpzjw.streamlit.app/

## Technologies Used
- Python
- Pandas
- Scikit-Learn
- Logistic Regression
- TF-IDF Vectorizer
- Streamlit

## Features
- Real-time News Classification
- Interactive Web Interface
- Machine Learning Based Prediction
- Deployed on Streamlit Cloud
